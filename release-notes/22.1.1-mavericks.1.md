## Clang / LLVM 22.1.1 for Mavericks — first release

A from-source build of **Clang/LLVM 22.1.1** for **Mac OS X 10.9 (Mavericks)**, in two variants that
never coexist on one machine — install the one that matches where you'll *run* the compiler:

- **`mavericks-clang-22-native-…​.pkg`** — a clang that **runs on 10.9** (x86_64) and targets 10.9.
  This is the flagship: install it on a real Mavericks box. Installs to `/usr/local/mavericks-clang-22`;
  requires Mac OS X 10.9.5+.
- **`mavericks-clang-22-cross-…​.pkg`** — a clang that **runs on modern Apple-Silicon macOS** and
  **cross-compiles for 10.9** (x86_64). Install it on a current Mac to build Mavericks binaries.
  Installs to `/usr/local/mavericks-clang-22-cross`.

Both are **batteries-included**: `clang++ hello.cpp -o hello` produces a working `x86_64` 10.9 binary
out of the box — the toolchain bundles a modern `libc++`/`libc++abi`/`libunwind`, `lld`, and the
[macports-legacy-support](https://github.com/macports/macports-legacy-support) polyfill for
newer-than-10.9 APIs, and it fetches the pinned 10.9 SDK on first use. Emitted binaries depend only on
system libraries present on every 10.9 install.

Add the variant's `bin/` to your `PATH` (e.g. `/usr/local/mavericks-clang-22/bin`).

Both variants are cross-built on a modern runner and gated by a 10.9-compatibility check on every
shipped binary; the native toolchain has additionally been verified building and running on real
Mavericks hardware.
